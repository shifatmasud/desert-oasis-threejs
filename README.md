# Desert Oasis — Golden Hour (Three.js)

Interactive Three.js golden-hour desert oasis scene featuring:
- **Optical Oasis Water**: Schlick Fresnel reflections, Beer-Lambert depth absorption, RGB chromatic dispersion Voronoi caustics, Snell's-law refracted sand-bed ripples, cat's-paw wind patches, and dual-lobe GGX sun glints.
- **Lush Palm Canopies**: 3-tier arching fronds with custom backlit subsurface scattering, organic seeded trunk curves, and Quixel Megascans palm/fern/bark assets.
- **Atmosphere & Post-Processing**: Volumetric god rays, low-lying drifting FBM mist, fine golden dust motes, `UnrealBloomPass`, and a custom filmic pass.
